# Unitree Go1 visual assets

Unmodified source assets from https://github.com/shinobi-wolf/go1-locomotion-rl/tree/f4fb0d12ac68842c1567bf1de6f771ce8e6671b5/unitree_go1

The upstream description derives from Unitree Robotics' public Go1 description:
https://github.com/unitreerobotics/unitree_ros/tree/master/robots/go1_description

The five binary STL files and go1_torque.xml are original model inputs, not generated build output. STL vertices use metres and their original link coordinate frames. The viewer applies the MJCF body origins, visual quaternions and twelve joint angles. The MJCF foot spheres are retained; collision proxy boxes/capsules are not displayed. This replaces the previous hand-built schematic robot; it does not change the simulator physics model.
