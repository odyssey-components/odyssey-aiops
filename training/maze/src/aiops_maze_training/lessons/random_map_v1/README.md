# 第二课：观察随机道路

保留第一课，增加“道路结构”这一项学习内容，仍使用专家模仿学习。

- `environment.py`：两端一致的种子生成器；151 维完整地图观测；每条专家样本含地图身份；训练/验证/测试地图内容去重。
- `model.py`：151→128 tanh→3 网络、真实逐局行走和 v2 模型导出；推理不调用专家。
- `train.py`：默认 256 张训练图、64 张验证图、100 张测试图、160 轮、seed=7。每10轮比较验证通关率，最后只对选中的模型测独立测试集。

仓库根运行 `uv run --project . --no-sync aiops-maze-train --lesson random-map-v1`。
`--maps 16 --epochs 0` 是小规模未训练对照；不是续训。生成的 `report.json` 保留实际种子、逐轮曲线、验证记录、选中轮次和初始/最终测试轨迹。

该次默认配置实测独立100图：未训练0张通关，训练并验证选择后63张通关。此结果不保证每次新图成功，也不适用于任意地图：仍固定7×7、起点(1,1)、出口(5,5)，并刻出一条向东/向南的通路。

完整学习说明见产品 `docs/courses.md`。
