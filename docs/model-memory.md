# 第四课：模型学习记忆

第三课是“程序替你记路”：程序保存已知地图和访问记录，模型每次读取这张记录表。第四课把这张表从模型输入里拿掉，改为让模型把过去的信息压进自己的隐藏状态。

可以把隐藏状态理解成随身带着的32个数字。每次看见新画面，模型既看当前观察，也看上一次留下的数字，再生成新的数字和当前动作。它们不是32条可读的文字，也不能把某一个数固定解释为“记住左边有墙”。

## 先在网页里做实验

1. 选择「迷宫 → 第四课：模型记忆」。仍是3×3视野、未知迷雾和200动作上限。
2. 加载本课模型后，右侧会显示32个隐藏数值与「已处理1次观察」。初始画面也算一次观察。
3. 手动走几步，或用专家单步。每个实际动作后处理一次新观察，转向和撞墙也算。
4. 切换控制方式或速度：隐藏状态保持。模型随后接手时，携带之前手动/专家动作形成的观察历史。
5. 点击「清空模型记忆」：停下自动运行，位置、步数和程序探索图保持；隐藏状态从零重新处理当前观察，计数回到1。比较动作概率，但同一位置清空前后的最高概率动作不一定不同。
6. 重置、换图或加载另一个模型：回到起点重新开始记忆。刷新只恢复URL中的选择，动作历史不恢复，保持暂停。

主图的累计探索记录用于让你看懂路线，也供专家生成示范。**它不会作为第四课模型的输入**。可视化“记住的地图”和GRU隐藏状态是两件事。

## 模型这次看什么？

| 输入 | 数量 | 意义 |
| --- | --- | --- |
| 当前3×3的墙 | 9 | 眼前哪些格子是墙 |
| 当前3×3的出口 | 9 | 眼前是否看到出口 |
| x、y位置 | 7+7 | 当前准确位置 |
| 朝向 | 4 | 东、南、西、北 |
| 上一个动作 | 4 | 没有上一步、左转、右转、前进 |
| 合计 | 40 | 当前观察，没有累计地图或访问平面 |

上一动作是实际执行的动作，手动控制、专家和模型都一样；即使前进撞墙，也记录为前进。位置和朝向由环境准确提供，本课尚未模拟机器人定位误差。

传感器仍是第三课的简化规则：以角色为中心的方形3×3，含对角格，不模拟墙后遮挡。网络输入可以看见附近，但不能读取远处的真实道路。

## GRU做了什么？

```text
当前40维观察 + 上一次32维隐藏状态
                  ↓
               GRU更新
                  ↓
新的32维隐藏状态 → 线性层 → 3个动作分数 → 概率
       ↓
  留给下一次观察
```

GRU中的“门”是学习出来的数值控制：哪些过去的信息继续保留，哪些内容根据当前观察更新。训练时，这些控制规则和动作判断一起被调整。

固定模型参数代表训练学到的规则；隐藏状态代表这一局里随经历变化的临时记录。重置会清空临时记录，不会把训练好的参数抹掉。

## 怎样训练？

在仓库根目录执行：

```bash
uv run --project . --no-sync aiops-maze-train --lesson memory-map-v1
```

默认CPU、256张训练地图、160轮。64张验证地图用于选择权重，100张独立测试地图只用于测量结果；地图内容跨组去重。模型从初始参数开始，不自动续训。

教师沿用第三课专家：只根据已观察道路生成探索动作。每张地图的样本按时间顺序组成一个episode，训练时可以打乱不同episode的顺序，不能打乱同一episode内部的观察。每个episode从零隐藏状态开始；不同长度序列补齐的空白步不计算损失。

因此，一条当前观察对应的答案可能依赖之前的经历。序列训练让模型有机会把有用的经历保存在隐藏状态中，而不是要求仅凭这一帧就猜出答案。

做小规模未训练对照：

```bash
uv run --project . --no-sync aiops-maze-train --lesson memory-map-v1 --maps 16 --epochs 0
```

输出仍在 `~/.odyssey/odymaze/runs/<时间>/`：

- `model.onnx` 与 `model.manifest.toml`：标准推理模型和协议清单，显式输入hidden、输出next_hidden；详见[ONNX说明](onnx-models.md)。
- `model.json`：v4课程协议、`gru`中的门权重、输出层和训练摘要。
- `samples.json`：按`maze_id`分组、按时间排列的观察、状态、上一动作和专家动作；没有把累计探索图放进输入。
- `report.json`：损失/动作正确率、验证选择、独立测试，以及同一模型每步清空隐藏状态的`reset_hidden`对照。

网页保留模型下拉，默认本课首个有效模型，不提供“请选择模型”空选项。训练完刷新本课列表后即可加载。

## 本次实际结果意味着什么？

2026-11-19 Linux CPU默认实验：seed7，256张训练图、3294条有序样本、160轮，由验证集选中第30轮（验证64图中96.875%通关）。独立100图：

| 运行方式 | 通关 |
| --- | --- |
| 未训练GRU | 0 / 100 |
| 训练后的GRU，保留历史隐藏状态 | 91 / 100 |
| 同一组权重，每一步清空隐藏状态 | 9 / 100 |

这次对照中，保留隐藏状态对结果有明显帮助。它不能证明隐藏状态形成了一张正确地图，也不能说明所有GRU都比第三课好：第三课与第四课的输入、网络和默认训练量也发生了变化，不能把跨课成功率差异全部归因于记忆。

固定7×7、固定起终点、向东/南可达的生成规则仍然限制实验。模型可能学到方向、动作顺序等规律；要证明能应对任意出口、复杂迷宫或现实机器人，需要新的环境和独立验证。本课的目标是看懂“训练参数”和“每局隐藏状态”的区别，并能亲手观察有无历史的对照。
