# 第三课：局部观察与程序记忆

第二课像拿着完整地图走路，第三课像拿着手电筒走进陌生地方：只能看到附近，程序帮你把看过的地方画下来。先理解探索与记路，第四课再学习让模型自己保留历史。

## 先在网页上观察

1. 打开「迷宫 → 第三课：局部探索」。没看过的格子是 `?`，不会提前显示出口。
2. 选「手动」，转向或前进，比较主图上的当前视野描边与下方 3×3 视野。走过的格子单独留有记录。
3. 选「专家」并单步：还没看到出口时，专家寻找最近的未访问道路；发现出口后，才在已知道路中寻找去出口的路径。可能先回到走过的路，再去探索新的路口。
4. 点「重置」：回到起点，清空本局记忆；模型参数仍保留。
5. 换一个种子再生成迷宫。第三课最多执行 200 个动作；左转、右转、撞墙都计一步。

这里的“看见”是一个简化传感器：角色周围方形3×3格，包含对角格，不模拟墙的遮挡；角色位置和朝向准确已知。地图仍为7×7，起点(1,1)、出口(5,5)，并保证存在向东/南的道路。这是学习探索记录的环境，不模拟现实机器人定位与视觉。

## 谁负责什么？

| 部分 | 现实含义 | 本课实现 |
| --- | --- | --- |
| 传感器 | 看附近 | 只揭示3×3范围内的格子 |
| 程序记忆 | 拿笔画下见过的道路 | `known`记录墙/道路/出口/未知，`visited`记录走过的位置 |
| 专家 | 示范怎样探索 | 只根据已知地图规划，不读取迷雾后的真实格子 |
| 模型 | 学习示范后判断当前动作 | 输入观察记录，输出左转、右转、前进三个分数 |
| 环境 | 执行动作后发生什么 | 移动、撞墙、到出口或超时 |

每一个动作都沿着这条链发生：

```text
当前观察和记忆 → 选择动作 → 环境更新 → 看附近 → 更新程序记忆
```

真实地图只在环境判断碰撞、出口，以及传感器读取附近时使用。编码和专家接收的是记忆；模型推理不会调用专家。看过但没走过的道路，与真正访问过的道路分开表示。

## 为什么需要249个输入？

程序把记录展开成五张7×7的数字表：

- 已知：见过为1，未知为0。
- 墙：已经看见的墙为1。
- 出口：已经看见的出口为1；尚未发现时全0。
- 访问：真正到达过的位置为1。
- 角色：当前位置为1。

五张表共245个数，加上东/南/西/北的四个朝向数字，得到249维。已知表让模型区分“尚不知道有没有墙”和“已经确认是道路”。

网络为 `249 → Linear(64) → Tanh → Linear(3)`。每次调用都读当前记录，网络内部没有跨步记忆。这一课中，“记住过去”是程序的工作。

## 动手训练

在仓库根目录执行：

```bash
uv run --project . --no-sync aiops-maze-train --lesson local-map-v1
```

默认CPU、128张训练地图、120轮。64张验证地图选择权重，100张独立测试地图衡量通关；三组地图内容去重。训练使用专家实际探索时的一串观察记录，不把完整地图专家的答案偷偷交给局部模型。

输出包含 `model.onnx`、`model.manifest.toml`，并保留 `model.json`、`samples.json`、`report.json`，默认放入 `~/.odyssey/odymaze/runs/<时间>/`。训练后在网页第三课刷新模型列表，默认加载本课第一个有效模型，也可从下拉框切换，没有“请选择模型”空选项。然后切到「模型」执行一步或自动运行。

打开 `samples.json`，一条样本中的 `memory.known` 是当时已经看见的地图，`memory.visited` 是当时走过的位置，`observation` 是展平后的249个数字，`action` 是当时专家的选择。后续揭示不会修改之前保存的样本。

做未训练对照：

```bash
uv run --project . --no-sync aiops-maze-train --lesson local-map-v1 --maps 16 --epochs 0
```

每次从初始网络开始，默认不续训。不同轮次是同一课的实验，不需要创建另一个适配器。

## 如何判断有没有学会？

2026-11-19 Linux CPU实测：默认seed7、128张图、1656条专家样本、120轮，验证选择第120轮，验证成功率57.8125%；100张独立测试地图上，未训练模型0张通关，训练后53张通关。没有调用规划器替模型兜底。

这意味着模型学到了一部分探索动作，同时仍会在某些地图绕圈或超时。训练集动作正确率、专家通关和模型通关是三个不同结果；不能因为专家能走完，就说模型也能走完。固定起终点也可能被网络学成位置偏好，本课不能证明它能应对任意出口或现实环境。

接下来可比较专家与模型的访问轨迹、看到出口的时机、回头行为和失败的地图。[第四课](model-memory.md)研究GRU如何保留历史，第三课的实现继续独立保留。
