# 第一课：固定地图，从零学习五个知识点

本页保留第一课的原始学习路径。第二课与两课比较见 [课程说明](courses.md)。

你现在不需要理解所有数学。先能回答：**给模型什么信息，它输出什么，训练程序怎样让它做得更好？**

这一版的完整流程是：

```text
地图规则           专家答案             调整模型              使用模型
位置 + 朝向   →   正确动作    →   预测、比较、更新    →   输入、概率、选择动作
```

先按 [README](../README.md) 启动页面。前四次实验不需要修改代码。

## 第 1 课：环境怎样回应动作

**目标：理解一步游戏，不涉及学习。**

地图是 7×7 方格：`#` 是墙，`.` 是通道，`G` 是出口。角色从 `(1, 1)` 出发，朝东。x 向右增加，y 向下增加。网页坐标从 0 开始。

角色只能执行三个动作：

| 动作编号 | 名称 | 结果 |
| --- | --- | --- |
| 0 | 左转 | 位置不变，朝向逆时针转 90° |
| 1 | 右转 | 位置不变，朝向顺时针转 90° |
| 2 | 前进 | 向朝向移动一格；撞墙则留在原地 |

注意动作编号与朝向编号不同：朝向东、南、西、北分别是 0、1、2、3。

**实验：**左转，再前进。位置仍是 `(1, 1)`，朝北，步数变成 2；日志会显示撞墙。再重置，右转并前进，角色移动到 `(1, 2)`。

- 一步（step）：执行一次动作，转向和撞墙也计步。
- 一局（episode）：从重置开始，到出口或到达 100 步上限结束。
- 状态（state）：位置、朝向、已走步数、是否结束。
- 观测（observation）：送进模型的信息。本课只有位置和朝向。

读 [environment.py](../training/maze/src/aiops_maze_training/lessons/fixed_map_v1/environment.py) 的 `State` 和 `step`，用纸笔预测下一步，再用网页核对。先不读专家和训练部分。

## 第 2 课：谁提供正确答案

**目标：理解训练数据从哪里来。**

专家是一段普通的寻路程序，不是另一个训练出来的模型。它从出口向外逐层计算距离，这种方法叫广度优先搜索（BFS）。距离为 1 的格子只要移动一次就能到出口，距离为 2 的格子需要移动两次，以此类推。

专家选择一个距离更小的邻居，再判断自己要转向还是前进。相反方向需要先转两次；它的距离最短指移动格数，不是为所有朝向搜索最少转向次数。

**实验：**重置，切到专家，执行一步。专家选择右转。自动运行时总共 12 个动作到达出口。

一条训练样本由两部分组成：

```text
模型的输入：x = 1，y = 1，朝东
专家的答案：右转（动作 1）
```

答案也叫标签（label）。我们问专家：这张地图上每个可达、非出口位置，朝四个方向时分别该做什么？17 个位置 × 4 个朝向，共 68 条样本。它们包含固定起点路线之外的位置，因此手动走到旁边的通道，也能观察模型怎样反应。

读 `expert_action` 和 `samples`。训练后打开 `samples.json`，找出起点的四条样本。**不要把专家答案放进模型输入**，否则模型只是在读取答案。

## 第 3 课：模型怎样给出概率

**目标：区分规则程序、模型结构和学到的参数。**

网页上模型的输入是 18 个数，分三组：

```text
x = 1： [0,1,0,0,0,0,0]  ← 7 个数，第 1 号位置为 1
y = 1： [0,1,0,0,0,0,0]  ← 7 个数
朝东：  [1,0,0,0]         ← 4 个数
```

这种“只亮一位”的表达叫 one-hot 编码。它让网络容易区分不同位置，不表示位置之间的远近。

本课的小神经网络只有：

```text
18 个输入 → 32 个隐藏单元（tanh） → 3 个动作分数 → 3 个动作概率
```

- 权重（weight）和偏置（bias）是模型内部可调整的数字，也叫参数。
- 隐藏层把输入组合成中间结果；tanh 是把数值变换到 -1 与 1 之间的函数。
- 输出层得到三个分数（logits）；softmax 把它们变成总和为 1 的概率。
- 运行时选概率最大的动作。平局按左转、右转、前进的顺序选择。

概率代表模型的选择倾向，不是“这个动作保证正确”的证明。

**实验：**生成 `--epochs 0` 的模型并加载。这个模型已经可以输出概率，但还没学习。对照训练后的模型，看看起点的右转概率怎样变化。

读 [model.py](../training/maze/src/aiops_maze_training/lessons/fixed_map_v1/model.py) 的 `make_model`，再读网页 [core.ts](../web/core.ts) 的 `probabilities`。网页的矩阵计算对应 Python 里的两个 `Linear`；不需要在浏览器安装 PyTorch。

## 第 4 课：训练究竟改变了什么

**目标：理解唯一的训练循环。**

从仓库根目录运行：

```bash
uv run --project . --no-sync aiops-maze-train
```

模型最初的参数是随机数。每一轮都对同一批 68 条样本执行四件事：

1. **预测：**根据每条观测，给出三个动作的分数。
2. **比较：**计算预测与专家标签的差距，得到损失（loss）。这里用交叉熵：给正确动作的概率越低，处罚越大。
3. **求调整方向：**`loss.backward()` 计算各个参数的梯度，可以先理解为“参数变化会怎样影响损失”。
4. **更新：**`optimizer.step()` 使用 Adam 方法调整参数，让模型更倾向于专家动作。

`optimizer.zero_grad()` 清掉上一轮的梯度，避免无意累加。学习率 0.03 控制更新的尺度。默认 400 轮（epoch）表示重复学习这批样本 400 次，不是玩 400 局。

训练没有修改地图，也没有把专家程序装进模型；变的是同一个网络里的参数。

输出中的损失和正确率都在每轮更新后测量：

- 损失：预测与答案的差距。
- 正确率：68 条样本中，概率最大的动作有多少与专家一致。
- seed：随机初始化的种子；相同 seed 方便做轮数对照，不保证不同环境逐 bit 一致。

**实验：**分别运行 0、10、50、400 轮，记录最终损失、正确率和实际是否通关。每次使用新的默认输出目录；训练从初始网络开始，不续接上一次运行。

读 [train.py](../training/maze/src/aiops_maze_training/lessons/fixed_map_v1/train.py) 的 `train`，只关注有注释的训练循环。先不研究命令行参数和输出文件处理。

## 第 5 课：训练完，怎样知道有没有用

**目标：理解导出、推理和评估。**

训练程序将网络导出为 `model.onnx` 和配套清单，同时保留可读的 `model.json` 供离线理解。网页列出有效ONNX模型，通过ONNX Runtime WASM执行同样的网络计算：

```text
当前观测 → 参数计算 → 动作概率 → 选一个动作 → 环境执行 → 下一次观测
```

这叫推理（inference）。推理不会继续调整参数，所以你在网页多走几局，模型不会自动变聪明。

**实验：**加载训练后的模型，先单步，再自动运行。暂停观察概率，切回手动移动几步，再让模型接管。模型清单或文件损坏时，页面会明确提示，不能用旧预测继续运行。

三个问题要分开看：

| 问题 | 怎么回答 | 本课是否覆盖 |
| --- | --- | --- |
| 模仿专家像不像？ | 对 68 条样本计算动作正确率 | 是，但这是训练集成绩 |
| 固定起点能通关吗？ | 让模型真实走一局，记录动作与结果 | 是 |
| 换一张陌生地图也能通关吗？ | 在未训练的新地图上独立测试 | 否，需要后续学习 |

`report.json` 的 `initial`、`final` 保存训练前后真实轨迹；`history` 保存每一轮损失和正确率。网页每局的通关判断来自实际角色是否走到 G，不读取模型摘要里的成功字段。

## 学完后再扩展

先能从头解释这五课，再每次只引入一个问题：

- 换起点或朝向：检验固定地图覆盖程度。
- 换地图：研究模型需要看到什么信息，而不是只记坐标。
- 模型走偏：研究让专家为模型自己的轨迹补标答案。
- 不给专家答案：研究奖励和强化学习。

随机地图已作为独立第二课提供，见 [课程说明](courses.md)。第一课仍保持原来的训练循环，其他问题以后再逐步学习。
