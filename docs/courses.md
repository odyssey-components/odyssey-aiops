# 两课训练方案：保留学习的每一步

AIOps 按课程保存训练方案。第一课保持原来的固定地图，第二课新增随机地图；切换课程不会把第一课升级成无法回看的版本。

## 两课分别学什么

| | 第一课：固定地图 | 第二课：随机地图 |
| --- | --- | --- |
| 学习目标 | 熟悉一条固定路线 | 观察道路结构，在多张地图上模仿寻路 |
| 课程 ID | `fixed-map-v1` | `random-map-v1` |
| 地图 | 原有 maze.json | 可复现种子的 7×7 随机道路 |
| 起点与出口 | 原样保留 | (1,1) 朝东 → (5,5) |
| 模型输入 | 位置、朝向，18 个数字 | 墙、出口、角色三个地图平面及朝向，151 个数字 |
| 网络 | 18 → 32 tanh → 3 | 151 → 128 tanh → 3 |
| 训练方法 | 专家动作模仿 | 专家动作模仿 |
| 怎样检查效果 | 固定起点真实通关 | 在独立地图上统计成功率和实际轨迹 |

这里的“适配器”就是一套明确的编码、模型和训练方案，不是外部插件。Python 放在 `training/maze/src/aiops_maze_training/lessons/`，网页课程代码放在 `web/src/lessons/`。旧 Python 模块路径保留兼容入口，学习时可直接进入对应课程目录。

## 从第一课开始

仓库根目录：

```bash
uv run --project . --no-sync aiops-maze-train
# 等价于显式选择第一课
uv run --project . --no-sync aiops-maze-train --lesson fixed-map-v1
```

第一课仍默认训练 400 轮。已有 `odymaze-policy/v1` 模型即使没有 `lesson` 字段，也会被识别为第一课，不要求重新训练或改文件。

## 再学习第二课

```bash
uv run --project . --no-sync aiops-maze-train --lesson random-map-v1
```

可以用 `--epochs 0` 创建未训练对照，使用 `--maps` 控制训练地图数；具体默认值和边界见 `--help`。每次运行从初始网络开始，不自动续训。

第二课的数据流：

```text
随机生成多张可达地图
         ↓
专家为地图内的位置与朝向提供正确动作
         ↓
观测：完整地图和当前位置 → 答案：专家动作
         ↓
反复预测、计算损失、更新参数
         ↓
验证集选择模型，最后在独立测试地图上实际走一局
```

### 为什么需要完整地图

第一课只提供位置和朝向，模型可以熟悉“这个坐标应该怎么走”。第二课同一个坐标周围道路可能不同，因此必须提供道路结构。

第二课将信息拆成三个 7×7 的平面，每格为 0 或 1：

1. 墙平面：墙的位置为 1，其余为 0。
2. 出口平面：只有出口为 1。
3. 角色平面：只有当前位置为 1。

再加上四个朝向数字，共 `49 + 49 + 49 + 4 = 151`。模型没有得到专家距离或答案，运行时也不会调用专家替它选择动作。

### 随机不等于无解

随机生成内部墙后，程序会刻出一条起点到出口的通路，保证地图可达。相同种子在 Python 和网页得到同一地图，因此你可以复现某次失败，而不是只能描述“刚才那张地图”。

这仍是一类特定迷宫：固定尺寸、固定起终点，且保证有一条向东/向南的通路。不能把这一课的成绩推广到任意尺寸、任意起终点和无解地图。

### 三类地图各有什么作用

- 训练地图：用于生成样本并修改模型参数。
- 验证地图：观察未训练地图表现，并选择训练过程中的模型。
- 测试地图：最后一次独立测量，不参与参数更新或模型选择。

划分同时比较地图内容，避免“种子不同但生成了相同道路”混进不同集合。报告保留各集合的实际种子，可复现数据。

`accuracy` 只说明样本动作是否接近专家。真正的寻路表现看逐局评估：是否到出口、实际步数、动作序列。新地图可能失败或绕圈，网页会正常到达 100 步上限并停止，不把报告里的成功摘要当成游戏结论。

## 在网页中比较两课

1. 选择“第一课：固定地图”，加载旧模型，观察原来的 18 个输入与 12 步专家路线。
2. 切换“第二课：随机地图”，查看完整地图输入，使用种子生成新迷宫。
3. 加载第二课训练的模型，单步观察概率，再自动运行；换一张图继续使用同一个模型。
4. 加载第一课模型会自动回到第一课，避免用固定地图参数控制随机地图。

切课、换图、加载或重置都会停止自动运行并重置相应局面。错误或不兼容模型会给出原因；未知课程不会自动冒充第一课。

## 不要混淆课程和实验结果

`fixed-map-v1` 与 `random-map-v1` 是两套课程方案。第一课训练 10 轮、50 轮和 400 轮，只是同一课的三次实验；不应为每次运行再建立一个适配器。

之后增加局部视野、记忆或强化学习，可以作为下一课。每课先写明新增问题和与上一课的差别，再增加实现，才能逐步理解训练路径。

## 用地址栏保存学习位置

页面按 OdyLab 的方式使用 Router 同步选择：`course` 是课时、`seed` 是地图种子、`mode` 是控制方式、`speed` 是自动运行间隔。切换这些设置会更新 URL，刷新或前进/后退可以恢复。

例如：`/?course=random-map-v1&seed=42&mode=expert&speed=40` 表示第二课、种子42、专家控制、快速。旧point参数仅兼容解析；说明性学习环节已移到文档，不在操作页显示。

默认目录模型可用 `model=<run名称>` 恢复，并通过原来的只读接口校验后加载。链接在另一台没有该模型文件的机器上会明确报错。模型目录固定为 `~/.odyssey/odymaze/runs/`，进入课时默认自动使用本课有效列表中的第一个模型（目录名倒序），保留模型下拉框且仅列出真实模型；刷新列表自动加载新的首项，仍保留手动/专家/模型模式和暂停状态。已有显式 model 链接仍可恢复，读取失败会明确提示。

自动运行、已经走过的步骤和轨迹不放进 URL。刷新后从起点暂停，不会自动运行；切课或换种子也会停止旧局，避免后台继续执行。

## 第三课：局部探索

前两课保留，新增第三课逐步揭示地图，程序记录观察与访问，模型读取249维记录选择动作。训练示范来自同样只看已知区域的专家。见[第三课完整教程](local-exploration.md)。

## 第四课：模型记忆

前三课保留；第四课把累计探索记录从网络输入中去掉，使用40维当前观察和32维GRU隐藏状态，按完整轨迹训练。页面可清空模型记忆但保留环境，报告保存每步清空hidden的对照。见[第四课完整教程](model-memory.md)。
