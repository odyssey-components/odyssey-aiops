# 在网页准备地图和训练

每个课时提供「训练任务」和「地图组」等工作区。训练流程：

1. 切换「地图组」，右上角点击「添加地图组」打开表单，填写地图组名称、说明、种子和地图数量，点击表单中的「添加地图组」。第一课保留原固定地图；第二至四课另外准备 64 张验证图、100 张测试图，组内三个集合按地图内容去重。
2. 切换「训练任务」，默认展示本课历史任务列表；右上点击「添加训练任务」，在弹窗中选择已经准备好的本课地图组、初始化种子和轮数，点击「开始训练」。创建成功后自动进入该任务详情。训练从这些地图提取本课专家样本，轮次中不再生成地图；调整初始化种子或轮数不改变地图组。
3. 列表的「详情」可进入指定任务，展示地图组、参数、起止时间、状态、通关率曲线和 Python 日志，可取消正在运行的任务。点击「返回任务列表」回到列表。成功后刷新本课模型列表，切换「实验」查看模型。0 轮是未训练对照，不代表完成学习。

刷新或切课不会重新启动任务，可以重新查看该课任务。取消/失败不发布不完整模型。服务退出时停止所属 Python 子进程；意外退出后 Python 也会检查父进程并停止。重启服务后不会将旧任务误报为运行中，已保存地图组与完整模型仍保留。任务列表从原有 job.toml 恢复，新的任务也保存有界日志和指标；旧任务未曾保存的内容显示为空，不补造曲线。详情通过 task UUID 写入 URL，支持直达、刷新、前进后退；切课回到该课任务列表。

## 一个地图组一对文件

固定目录为 `~/.odyssey/odymaze/datasets/`：

```text
<组ID>.jsonl
<组ID>.toml
```

该次生成的所有地图保存在同一个 JSONL 中，一行一张，不为每张地图单独创建文件。每行包含 `split`（train/validation/test）、`id`、7×7 的 `cells`、`start` 和 `max_steps`。数值约定为 `-1` 墙、`1` 道路、`0` 目标；角色的位置和朝向不占用地图格子的编码。

同名 TOML 保存以下信息：

| 字段 | 用途 |
| --- | --- |
| format / map_format | 地图组与数值网格的版本 |
| id / title / description | 组标识、名称、说明 |
| created_at / lesson / seed | 带时区的生成时间、所属课时、生成种子 |
| rows / columns / max_steps | 尺寸与动作上限 |
| wall_value / road_value / goal_value | -1 / 1 / 0 的含义 |
| generator | 固定地图或随机地图算法版本 |
| split_counts | 训练、验证、测试地图数量 |
| sha256 | 整份 JSONL 的摘要 |

名称最长 80 字符，说明最长 500 字符。元数据使用 TOML 字符串保存，支持中文、引号和换行。日期以带时区的 ISO 8601 保存，网页按浏览器本地时区显示。描述文件写入完成后该组才可选；不会覆盖已有文件。缺少配对文件、摘要不匹配、规格/课时/计数错误、无效格子或重复地图都会拒绝训练。

这是世界地图的存储格式，现有各课模型的输入编码保持兼容；局部观察中「尚未观察」仍用独立观察/记忆状态表示，不能把它当目标值 0。

## 本地后台与边界

Go 服务只在回环地址提供训练接口，写操作要求同源 Origin 和 JSON 请求。后台以固定 argv 调用独立环境中已安装训练 wheel 的 Python，不接收 shell、命令或输出目录。Maze 与 Go1 共用串行执行器，网页训练按队列执行，地图数 16–512、轮数 0–1000；准备上限 2 分钟、训练上限 15 分钟，只使用本机 CPU。第一课地图数固定为 1。

每个任务在 `~/.odyssey/odymaze/jobs/<任务ID>/job.toml` 保存独立元信息：格式版本、任务 ID、动作、课时、状态、开始/结束时间、参数，以及地图组 ID/SHA-256、成功的 run ID 或失败原因。状态文件串行、原子更新；它是任务执行记录，重启后不会自动恢复执行。

训练任务直接关联 `datasets/<组ID>.jsonl` 与同名 TOML，不再复制地图到 job 目录。Python 读取时同时校验地图组元数据与 job 指定的 SHA-256；关联内容变化或文件缺失会拒绝训练。地图组按新 ID 创建、拒绝覆盖，当前没有地图组修改或删除接口。外部手工删除/修改仍会导致任务失败。

训练中间产物暂存在 job 的 `output/`，成功的 JSON/ONNX/清单发布到固定 `runs/`，清单仅关联地图组 ID 与 SHA-256，不保存地图副本。成功后 job 目录保留 `job.toml` 与有界日志/指标；失败或取消保留已有中间产物。此变更只影响新任务，不自动清理旧 job 或真实数据。日志只显示有界的最近输出。所有运行文件都不进入 Git。

原 CLI 默认行为保留；显式使用预生成地图时：

```bash
uv run --project . --no-sync python -m aiops_maze_training.common.datasets \
  --lesson random-map-v1 --maps 256 --seed 7 \
  --title '第二课课堂地图组' --description '固定训练/验证/测试地图，用于比较模型' \
  --output /path/to/new-group.jsonl

uv run --project . --no-sync aiops-maze-train \
  --lesson random-map-v1 --dataset /path/to/new-group.jsonl --epochs 160
```

第一条命令创建同名 `.jsonl` 和 `.toml`；第二条只读取该组。CLI 自选路径不等于网页可以选择任意目录；网页目录与参数范围固定。

在「地图组」表格末列点击「详情」查看该组名称、说明、数量、种子、创建时间、文件名与SHA-256；点击「返回地图组」回到列表。详情可通过URL刷新恢复，也支持浏览器前进/后退。

「模型」tab 按当前课时列出固定训练目录中的有效模型，标注当前使用项，点击「详情」查看训练参数、指标、模型格式、输入输出张量及SHA-256，点击「返回模型列表」回到表格；「刷新模型列表」重读目录，失败可重试。实验页仍保留当前模型快捷选择。

模型详情的「ONNX 文件信息」直接解析已校验SHA-256的ONNX二进制，展示生产工具、IR/模型版本、domain、opset、自定义元信息、实际输入输出和主图算子统计。展开权重张量与主图节点连接可查看名称、类型、形状、参数数量及连接。Initializer参数总数统计文件中的初始化张量元素，不等同于可训练参数数。缺失元信息显示未记录；结构读取失败可重试，训练信息仍保留，查看不启动推理。
